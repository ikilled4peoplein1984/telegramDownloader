# 📥 TG Downloader

Консольный загрузчик файлов из Telegram-каналов и групп.
Скачивает **архивы, видео, аудио, документы** — параллельно, с прогресс-барами,
докачкой и защитой от лимитов Telegram.

## ✨ Что умеет

- 🔐 Вход в Telegram по номеру телефона (сессия сохраняется — повторно входить не нужно)
- 🔎 Поиск канала по `@username`, ссылке `t.me/...`, ID или выбор из своих чатов
- 📜 Список всех файлов канала: архивы, видео, аудио, документы, фото
- ☑️ Гибкий выбор файлов: номера, диапазоны, `all`, по расширению, по подстроке
- 📁 Выбор папки и диска для сохранения
- ⚡ Параллельное скачивание **нескольких файлов** сразу
- 🧵 Многопоточная загрузка **одного большого файла** (файл делится на части)
- 📊 Прогресс-бары: общий + по каждому активному файлу
- 🚫 Пропуск дубликатов (по имени файла)
- 🛡️ Автоматическая обработка `FloodWait` — скрипт сам ждёт и продолжает
- 🚀 Поддержка `cryptg` — ускорение шифрования в разы

## 🚀 Быстрый старт (Windows)

### Шаг 1. Установи Python

1. Скачай Python **3.9 или новее** с [python.org](https://www.python.org/downloads/)
2. Запусти установщик
3. ⚠️ **Обязательно** поставь галочку **«Add Python to PATH»** внизу окна установки
4. Жми **Install Now**

Проверь, что всё встало — открой **cmd** (Win+R → `cmd` → Enter) и выполни:

```cmd
python --version
```

Должно показать что-то вроде `Python 3.12.0`. Если пишет «не является внутренней или внешней командой» — переустанови Python с галочкой `Add to PATH`.

### Шаг 2. Скачай проект

**Вариант А — через Git:**

```cmd
git clone https://github.com/ikilled4peoplein1984/telegramDownloader.git
cd telegramDownloader
```

**Вариант Б — без Git:**

1. Нажми зелёную кнопку **Code → Download ZIP**
2. Распакуй архив в удобное место, например `C:\telegramDownloader`
3. Открой cmd и перейди в папку:

```cmd
cd C:\telegramDownloader
```

### Шаг 3. Установи зависимости

В той же папке выполни:

```cmd
pip install telethon rich cryptg
```

> 💡 `cryptg` **критичен для скорости**. Без него шифрование идёт на чистом Python и режет загрузку в разы.

Если `cryptg` не ставится — попробуй:

```cmd
pip install cryptg --only-binary :all:
```

Если и это не помогло — пропусти `cryptg`, скрипт запустится без него, но медленнее.

### Шаг 4. Получи `api_id` и `api_hash`

См. отдельный раздел: [Получение api_id и api_hash](#-получение-api_id-и-api_hash).

### Шаг 5. Запусти

```cmd
python tg_downloader.py
```

Первый запуск спросит `api_id` и `api_hash` — введи их. Они сохранятся в `config.json`, больше спрашивать не будет.

## 🔑 Получение api_id и api_hash

Это **обязательный шаг**. Без ключей скрипт не заработает.

1. Открой https://my.telegram.org
2. Войди по **номеру телефона** (код придёт в сам Telegram, не SMS)
3. Нажми **API development tools**
4. Заполни форму:

   | Поле | Что вписать |
   |---|---|
   | **App title** | `TG Downloader` |
   | **Short name** | `tgdownloader` (только буквы и цифры, 5–32 символа) |
   | **URL** | `https://t.me` |
   | **Platform** | `Desktop` |
   | **Description** | `Personal downloader` |

5. Нажми **Create application**
6. Скопируй **App api_id** (число) и **App api_hash** (32 символа)

> ⚠️ **Никому не показывай `api_hash`.** С ним можно войти в твой аккаунт. Если случайно засветил — создай новое приложение и используй только его.

**Если при создании приложения вылетает `ERROR` без объяснений:**

- Отключи VPN или наоборот включи его (сервер должен быть в стране твоего номера)
- Отключи блокировщики рекламы (uBlock, AdBlock)
- Открой сайт в режиме инкогнито
- Попробуй с телефона через мобильный интернет (не Wi-Fi)

## 🏁 Первый запуск

После `python tg_downloader.py` произойдёт следующее:

```
api_id: 1234567
api_hash: abcdef1234567890abcdef1234567890
Please enter your phone (or bot token): +79991234567
Please enter the code you received: 12345
Please enter your password: ********
Signed in successfully as Имя
✓ Вошли как Имя (@username)
✓ cryptg установлен — быстрое шифрование включено.

Размер пула MTProto-соединений (1-12, Enter = 4):
```

**Что вводить:**

- **api_id** и **api_hash** — из [my.telegram.org](https://my.telegram.org)
- **Телефон** — в формате `+79991234567` (без пробелов)
- **Код** — придёт **в сам Telegram** (от аккаунта «Telegram»), не по SMS
- **Пароль 2FA** — если у тебя включена двухэтапная аутентификация
- **Размер пула** — нажми Enter (по умолчанию 4)

Дальше сессия сохранится. При следующих запусках логин не потребуется — только выбор канала.

## 🎮 Как пользоваться

### 1. Выбор канала

Скрипт спросит:

```
Укажите канал: @username, ссылку t.me/..., числовой ID, либо Enter — выбрать из ваших чатов.
Канал:
```

- Введи `@durov` — канал Павла Дурова
- Введи `https://t.me/durov` — то же самое
- Введи `-1001234567890` — числовой ID
- Нажми **Enter** — покажет список твоих каналов и групп, выбирай по номеру

### 2. Включить фото?

```
Включать фото? [y/N]:
```

- `n` или Enter — только документы (архивы, видео, аудио)
- `y` — плюс фотографии

### 3. Выбор файлов

Появится таблица со всеми файлами канала. Команды:

| Команда | Что делает |
|---|---|
| `all` | Выбрать **все** файлы |
| `none` | Снять всё |
| `1,5,10-20` | Добавить файлы №1, №5 и с №10 по №20 |
| `-3,7-9` | **Убрать** файлы №3 и с №7 по №9 |
| `ext zip rar` | Выбрать все архивы `.zip` и `.rar` |
| `find фильм` | Выбрать все файлы, где в имени есть «фильм» |
| `sort name` / `sort size` / `sort date` | Сортировка |
| `n` / `p` | Следующая / предыдущая страница |
| `page 3` | Перейти на страницу 3 |
| `go` | **Начать скачивание** |
| `q` | Выход |

Пример: скачать только видеофайлы `.mp4`, отсортированные по размеру:

```
sort size
ext mp4
go
```

### 4. Куда сохранять

```
Папка (Enter = C:\Users\User\Downloads\Telegram):
```

- Нажми Enter — сохранит в папку по умолчанию
- Или введи свой путь, например `D:\Video`
- Папка создастся автоматически

### 5. Настройки скорости

```
Настройки скорости (больше = быстрее)
Файлов одновременно (1-8, Enter = 2):
Потоков на один файл (от 20.0 МБ; 1 = выкл.) (1-8, Enter = 4):
```

См. [Настройки скорости](#-настройки-скорости). Для первого раза — просто Enter.

### 6. Старт

```
Начать? [Y/n]:
```

Enter или `y` — поехали. Дальше увидишь прогресс-бары:

```
ВСЕГО          ███████░░░░░░░░  45%  2.1/4.7 GB  4.8 MB/s  0:08:12
(1/3) video.mp4 ████████████░░░  78%  1.5/1.9 GB  3.2 MB/s  0:02:05
(2/3) film.mkv  ██████░░░░░░░░░  35%  0.6/1.7 GB  1.6 MB/s  0:11:30
```

Когда всё скачается, увидишь:

```
Готово. Скачано: 3, пропущено: 0, ошибок: 0
Папка: D:\Video
```

## ⚙️ Настройки скорости

Скрипт спросит два числа при каждом запуске. Вот что они значат:

| Параметр | Что делает | Рекомендую |
|---|---|---|
| **Файлов одновременно** | Сколько файлов качать параллельно | **2** |
| **Потоков на один файл** | На сколько частей бить один большой файл | **2** |
| **Размер пула MTProto** | Сколько соединений с Telegram открыть | **4** |

### Как выбрать под себя

| Твоя ситуация | Файлов одновременно | Потоков на файл | Пул |
|---|---|---|---|
| Просто, стабильно, без зависаний | **1** | **1** | **2** |
| Обычный режим (рекомендую) | **2** | **2** | **4** |
| Хочу быстро, готов ждать паузы | **2** | **3** | **6** |
| Максимум (только если Premium) | **4** | **4** | **8** |

> 📌 **Правило:** держи `Файлов × Потоков ≤ 4` для бесплатного аккаунта. Всё, что выше — Telegram начинает «тормозить» загрузку.

### Почему не гнаться за максимумом

Telegram **тихо ограничивает** скорость для бесплатных аккаунтов. Если поставить `8 × 4 = 32` одновременных запроса — сначала будет быстро, потом скрипт зависнет на 10 минут, потом «отпустит». Средняя скорость за час окажется **ниже**, чем при `2 × 2 = 4`.

**Парадокс:** меньше параллельности → меньше пауз → выше средняя скорость.

## 🔧 Частые проблемы

### `database is locked`

Причина: скрипт запущен **дважды одновременно**, оба лезут в один файл сессии.

Решение:

```cmd
taskkill /F /IM python.exe
cd C:\путь\к\проекту
del *.session-journal *.session-shm *.session-wal
```

И запусти **только один** экземпляр.

### `cryptg НЕ установлен`

Не критично, но скорость будет ниже. Поставь:

```cmd
pip install cryptg
```

Если не ставится — пропусти, скрипт всё равно работает.

### `FloodWaitError: A wait of N seconds is required`

Telegram просит подождать. Скрипт **сам подождёт** и продолжит. Ничего делать не надо.

Если `FloodWait` повторяется часто — уменьши настройки скорости:

```
Файлов одновременно: 1
Потоков на файл: 1
```

### Скорость упала почти до нуля и стоит

Это **тихий троттлинг** Telegram. Подожди 3–10 минут — само отпустит.

Если совсем не ждётся:
1. `Ctrl+C` в окне скрипта
2. `taskkill /F /IM python.exe`
3. В папке загрузки удали `*.part`
4. Запусти скрипт заново — уже скачанные файлы он пропустит

### `ValueError: Your API ID or Hash cannot be empty or None`

При вводе `api_hash` нажал Enter, не вставив значение. Запусти скрипт заново и **вставь** `api_hash` (правая кнопка мыши в cmd).

### `ERROR` при создании приложения на my.telegram.org

- Попробуй **другой VPN-сервер** (в стране твоего номера)
- Отключи **блокировщики рекламы**
- Открой в **режиме инкогнито**
- Попробуй с **телефона через мобильный интернет**
- Подожди **24 часа** — Telegram мог временно заблокировать создание приложений

### Русские буквы в именах файлов отображаются «кракозябрами»

Проблема с кодировкой терминала. На Windows:

```cmd
chcp 65001
```

Потом запускай скрипт.

### Скрипт падает с `AuthKeyUnregisteredError`

Ты завершил сессию через Telegram (Settings → Devices → Active Sessions). Нужно залогиниться заново:

```cmd
cd C:\путь\к\проекту
del *.session config.json
python tg_downloader.py
```

## ❓ FAQ

**Где хранятся скачанные файлы?**
По умолчанию — `C:\Users\ТВОЙ_ЮЗЕР\Downloads\Telegram`. Можно поменять при запуске.

**Сколько времени займёт скачивание?**
Зависит от размера и лимитов Telegram. Ориентир: **1–5 МБ/с** на бесплатном аккаунте. 100 ГБ ≈ 6–28 часов.

**Можно ли качать с закрытых каналов?**
Да, если ты **участник** этого канала. Скрипт работает от твоего аккаунта.

**Можно ли качать несколько каналов параллельно?**
Нет, по одному за раз. Но можно запустить второй экземпляр в **другой папке** с **другой сессией** (скопируй папку проекта и удали `*.session`).

**Это безопасно? Не забанят?**
Скрипт использует официальный API Telegram через библиотеку Telethon. Пока ты не превышаешь лимиты (см. настройки скорости) — бана не будет. **Не ставь `8 × 8`** — это уже похоже на ферму.

**Что делать, если файл битый?**
Проверь размер в проводнике. Если меньше ожидаемого — удали и скачай заново. Скрипт качает `.part`, и только при полном размере переименовывает в финальное имя.

**Нужен ли Telegram Premium?**
Нет, но с ним лимиты выше. На бесплатном тоже работает — просто медленнее.

**Как обновить скрипт?**
Если клонировал через Git:
```cmd
git pull
pip install -r requirements.txt --upgrade
```
Если скачивал ZIP — скачай заново и замени `tg_downloader.py`. `config.json` и `*.session` не трогай.

**Куда делись активные сессии? Их было 8.**
Каждая сессия пула — это отдельное «устройство» в Telegram. Это нормально. Чтобы уменьшить — поставь пул = 2.

## 🔐 Безопасность

- **`api_hash` — это половина ключа от аккаунта.** Никому не показывай, не выкладывай в Issues, не скриншоть.
- **`config.json`** содержит `api_id` и `api_hash` — не коммить в Git.
- **`*.session`** — это активный вход в аккаунт. Если файл утечёт, злоумышленник получит доступ к твоему Telegram.
- **`.gitignore`** уже включает эти файлы. Не убирай их оттуда.

### Если `api_hash` случайно засветил

1. Заверши все сессии: Telegram → Settings → Devices → Active Sessions
2. Смени пароль 2FA: Settings → Privacy and Security → Two-Step Verification
3. Создай новое приложение на [my.telegram.org](https://my.telegram.org) с новыми ключами
4. Удали `config.json` и `*.session` локально
5. Запусти скрипт заново с новыми ключами
